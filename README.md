# net-sim

서브넷 · ARP · DHCP · 게이트웨이 · NAT · TCP 가 **어느 지점에서 무엇을 보고 어떤 결정을 하는지** 눈으로 보기 위한 네트워크 시뮬레이터입니다.

```
npm install
npm run dev      # http://localhost:5173
npm test         # 코어 테스트
npm run ui-check # 브라우저 스모크 테스트
```

## 사용법
- 상단의 퀵 액션(예: `h1 → ping h2`)을 누르면 동작이 큐에 들어갑니다.
- `다음 ▶`(→) 로 이벤트 하나씩, `▶ 재생`(Space) 으로 패킷 애니메이션, `◀ 이전`(←) 으로 되감기.
- 오른쪽 패널은 각 노드의 상태 테이블(ARP 캐시, MAC 테이블). 방금 바뀐 행은 초록색.
- 아래 로그는 계층(L1/L2/L3/app/sys)별 필터, 행을 클릭하면 상세 JSON.

## 현재 단계
1. ✅ 단일 서브넷: 스위치 1 + 호스트 3, ARP 요청/응답, MAC 학습, ICMP ping, ARP 타임아웃
2. DHCP
3. 라우터/게이트웨이
4. NAT + 외부망
5. TCP
