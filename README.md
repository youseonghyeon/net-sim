# net-sim

서브넷 · ARP · DHCP · 게이트웨이 · NAT · TCP 가 **어느 지점에서 무엇을 보고 어떤 결정을 하는지** 눈으로 보기 위한 네트워크 시뮬레이터입니다. Packet Tracer 처럼 장치를 놓고 케이블을 연결해 직접 구성합니다.

```
npm install
npm run dev      # http://localhost:5173
npm test         # 코어 테스트
npm run ui-check # 브라우저 스모크 테스트 (.shots/ 에 스크린샷)
```

## 사용법
- 왼쪽 팔레트에서 PC·노트북·서버·스위치·라우터를 캔버스로 끌어다 놓습니다. 클릭하면 화면 중앙에 추가됩니다.
- 케이블 도구(C)로 장치에서 장치로 끌면 상대를 향한 빈 포트끼리 연결됩니다. Shift + 드래그도 같습니다.
- 장치를 선택하면 오른쪽에 이름·포트·IP 설정(자동/수동), 라우터는 LAN 주소와 DHCP 서비스 토글이 나옵니다.
- 휠로 이동, ⌘ + 휠로 확대·축소. Delete 로 선택 삭제. 작업은 브라우저에 자동 저장됩니다.

## 단계
1. ✅ 디자인 시스템 + 캔버스 에디터
2. DHCP 시뮬레이션 (라우터 토글, 자동/수동 IP)
3. ping · 패킷 애니메이션 · 이벤트 로그
4. NAT + 외부망
5. TCP
